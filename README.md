# ФОРМА

Сайт мебельной фабрики: каталог коллекций, новости, дизайнеры и оформление заказа. Интерфейс на русском и английском языках.

## Возможности

- Каталог: тип мебели, подтип, карточка товара и фотогалерея.
- Заказ нескольких товаров с расчётом стоимости и доставки.
- Отдельные страницы контактов, проезда и документов фабрики.
- Панель управления контентом, заказами и учётными записями менеджеров.
- Права доступа по разделам, проверка данных, защита форм и очистка HTML.
- Уведомления о заказах по SMTP с повторной отправкой при ошибке.

## Установка

Нужны PHP 8.2 или новее, MySQL 8.0 и расширения PDO MySQL, mbstring, DOM, fileinfo и cURL (для тестов). Веб-сервер должен использовать папку `public` как корень сайта. В Open Server настройка проекта находится в `.osp/project.ini`.

Соединение с базой задаётся переменными `RGR_DB_DSN`, `RGR_DB_USER`, `RGR_DB_PASSWORD` либо в локальном файле `config/local.php`, возвращающем массив настроек. Этот файл не публикуется.

```sh
php database/setup.php
php -S 127.0.0.1:8020 -t public router.php
```

Сайт: http://127.0.0.1:8020/ . Панель управления: http://127.0.0.1:8020/admin . При первом создании базы данные администратора сохраняются в `storage/first-login.txt`. Для существующей базы установщик не заменяет пользователей и каталог. Если база уже создана на хостинге, используйте `php database/setup.php --skip-create`.

Папки `storage` и `public/uploads` должны быть доступны PHP для записи. Не размещайте файлы настроек и базы данных внутри `public`.

## Почта

Параметры: `SMTP_HOST`, `SMTP_PORT`, `SMTP_TLS` (`starttls`), `SMTP_USER`, `SMTP_PASSWORD`, `MAIL_FROM`, `MAIL_TO`. Аналогичные ключи нижним регистром можно указать в `config/local.php`. Для локальной проверки используется SMTP-приёмник на порту 1025. Для доставки внешнему получателю необходимо подключить настоящий SMTP-сервер.

## Публикация на Vercel

Работающий сайт: https://web-rgr-furniture.vercel.app/ . Конфигурация находится в `vercel.json`: PHP выполняется через `vercel-php@0.9.0`, статические файлы собираются отдельно, исходники приложения недоступны по HTTP.

В облачной версии используется TiDB Cloud Starter с MySQL-совместимым подключением. Заказы, сессии и загруженные изображения хранятся в базе и не зависят от временной файловой системы Vercel. Локальный запуск с MySQL и Open Server сохранён.

Для окружений Production и Preview нужны секреты `RGR_DB_DSN`, `RGR_DB_USER`, `RGR_DB_PASSWORD` и `MAIL_TO`. Соединение с облачной базой использует TLS с проверкой сертификата. Почтовые уведомления включаются после настройки настоящего SMTP-сервера.

## Структура проекта

`app/controllers` обрабатывает запросы, `app/models` работает с данными, `app/views` содержит шаблоны. Схема и начальные данные находятся в `database`, статические файлы и PDF-документы в `public`.

## Проверки

При запущенном локальном сайте: `php tests/run.php`. Проверки охватывают маршруты, валидацию заказа, защиту форм, вход, права менеджеров и операции с контентом. Запускайте их на локальной тестовой базе, не на рабочем сервере.
